# AGO Chat operator console

The SPA operators work in: their queue, their active conversations, presence and history.

The framework (React or Angular) is deliberately undecided until roadmap Stage 5, and the choice will
be recorded as an ADR when it is made. Until then this repository holds nothing but this note — an
empty repository is more honest than a scaffold nobody chose.
